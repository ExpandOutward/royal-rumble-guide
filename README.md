# WWF Royal Rumble Interactive Strategy Guide
I created this application to improve my front-end web development skills. I chose to do a gaming strategy guide because it plays on my childhood interests. Before the internet, companies would publish strategy guides for specific games that were full of strategies, cheat codes, maps, move sets, and trivia. Every once in a while friends and I would start creating our own using notebooks and colored pencils. I took this learning opportunity to kill two birds with one stone. I learned more regarding web development and I scratched an itch I had when I was a kid. 

# Focus
This application was coded from scratch using raw HTML, CSS, and JavaScript. My primary focus going into this project was interactivity. I wanted the look and feel of a classic video game strategy guide with several interactive elements that would force me to focus on conditions.

## Interactive Elements
- Users can choose between Super Nintendo and Sega Genesis, with each selection displaying the system-specific talent roster.
- Each wrestler's finishing move can be viewed by clicking a button that plays a gif on a loop.
- The options menu allows the user to enable menu music that plays on a loop.
- The options menu also allows the user to enable wrestler-specific theme music that plays when a wrestler is selected.
- Volume controls were added for both music options.
